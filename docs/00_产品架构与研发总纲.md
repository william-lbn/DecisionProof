# DecisionProof 产品、架构与研发总纲

版本：V2.0 Engineering Foundation
日期：2026-07-24

## 1. 产品定义

DecisionProof（技术工程名继续兼容 SDLCProof）是一个“产品决策到生产结果的可信闭环平台”。它不以替代 Word、PPT、GitLab 或 Kubernetes 为目标，而是将这些系统中的事实连接成一条可以验证、追踪、授权和审计的数字主线。

平台必须回答：

- 这个产品为什么立项；
- 哪些客户、市场和经营证据支持这个决策；
- 原始 PPT、Word 和会议纪要中的目标、约束、风险来自哪里；
- 哪些内容经过人工确认和批准；
- 哪个工程就绪包被交给研发；
- 哪个 GitLab Issue、Commit、MR 和 Pipeline 实现了它；
- 哪个不可变制品被部署；
- 谁授权了发布；
- 灰度是否满足技术和业务边界；
- 最终产品目标是否实现。

## 2. 不是做什么

平台不是：

- 新的通用大模型；
- 另一个聊天式 Coding Agent；
- GitLab、Jira、Productboard、Word 或 PowerPoint 的全面替代品；
- 允许 Agent 自主获得生产管理员权限的自动发布器；
- 只生成文档但不验证工程和生产结果的“AI PRD 工具”。

## 3. 一期闭环

```text
Word/PPT/Markdown/会议纪要
→ 原始文档与来源锚点
→ AI 结构化提取
→ 人工确认和批准
→ Engineering Readiness Package
→ GitLab Issue / Branch / MR
→ 隔离 Coding Agent
→ 独立 Review Agent + 人工审查
→ GitLab CI 测试、安全、SBOM、Provenance、签名
→ 平台 Merge Qualifier
→ 不可变 Artifact Digest
→ Release Evidence Manifest
→ GitOps Staging
→ 测试验证
→ 人工生产批准
→ Argo Rollouts Canary
→ Prometheus 技术/业务指标
→ Promote / Pause / Rollback
→ Outcome Contract
→ 产品目标复盘和下一轮决策
```

## 4. 事实源边界

- 原始文档：对象存储、SharePoint/OneDrive 或客户文档系统；
- 产品决策、批准和工程基线：DecisionProof；
- 代码、Issue、MR、Pipeline、Job：GitLab；
- 构建制品：GitLab Container Registry 或后续 Harbor；
- 部署期望状态：GitOps 仓库；
- 部署实际状态：Argo CD、Kubernetes、Argo Rollouts；
- 技术指标：Prometheus/OpenTelemetry；
- 业务指标：企业指标平台；
- 跨系统关系和证据：DecisionProof Evidence Graph。

GitLab 是工程交付事实源，不是早期市场、商业论证和所有产品资料的唯一入口。

## 5. 核心原则

1. AI 输出必须有来源锚点；
2. AI 提取不等于正式决策；
3. 只有人工批准的对象才能进入工程基线；
4. Agent 只提出变更和动作；
5. 所有外部写操作通过 Tool Gateway；
6. Webhook 是通知，API Read-back 才是最终对账；
7. Evidence 必须精确绑定 Commit、Artifact、Deployment 或 Release；
8. 可变镜像标签不能作为发布身份；
9. Prometheus No Data 必须暂停，不能默认通过；
10. Outcome 失败不能被“部署成功”掩盖。

## 6. 当前 V2 工程实现

本工程已经在 P0 控制内核上新增：

- DOCX、PPTX、Markdown、TXT 原生解析；
- Source Document、Source Block 和来源锚点；
- 产品决策受控类型和 EXTRACTED/CONFIRMED/APPROVED 状态；
- 工程就绪包及 GitLab Issue/Docs-as-Code 确定性 Bundle；
- 模型无关 AI Extractor；
- 确定性开发提取器；
- 通用 HTTP JSON AI Adapter；
- GitLab REST Client；
- GitLab Webhook HMAC/Legacy Token、原子 File Inbox 和重复事件去重；
- Prometheus Query Adapter；
- 通用 Agent CLI 协议；
- Evidence V2 字段；
- Subject-bound Release Qualifier；
- Agent Release Manifest 和评估资格门；
- Outcome Contract Evaluator；
- 中文内嵌产品工作台；
- PostgreSQL V2 Schema；
- 单元、并发和故障语义测试。

## 7. 仍需完成的生产主链

- PostgreSQL 驱动、产品 Repository、Webhook Inbox 和运行时默认接入；
- Temporal SDK、Workflow 和 Worker；
- GitLab OAuth、Webhook Inbox/Reconciler 持久化；
- 真实 Codex/OpenHands K8s Agent Job；
- GitLab CI Template 的真实项目验证；
- Cosign/Syft/Trivy/Provenance 实际执行；
- GitOps MR、Argo CD 和 Rollouts Adapter；
- OIDC/KMS/Secret Provider；
- 多副本、高可用、备份恢复和 7×24 验证。

因此本包是“V2 工程底座”，不是已经完成的商业生产平台。
