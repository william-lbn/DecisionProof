# 验证计划与生产验收

## 1. 本包可验证

- P0 生命周期和证据链；
- 产品资料到工程就绪包；
- DOCX/PPTX 解析；
- GitLab Client 读重试和写不重试；
- Webhook HMAC；
- Prometheus 响应解析；
- Subject-bound Evidence；
- Outcome No Data/Failure；
- Race Detector、Vet、Build。

## 2. 单集群 E2E

多节点 K8s 集群中安装 GitLab 测试实例或连接独立 GitLab、PostgreSQL、Temporal、Runner、Argo、Prometheus、OTel、对象存储和 Agent Runtime。

验证完整 Issue → Product Baseline → Agent → MR → CI → Artifact → Staging → Canary → Outcome。

## 3. 生死故障

- 重复和乱序 Webhook；
- GitLab 已提交但响应丢失；
- Worker Activity 后被杀；
- PostgreSQL 主实例切换；
- OPA 不可用；
- Prometheus No Data；
- Argo 不可用；
- Agent 越权和 Prompt Injection；
- Artifact/Attestation 篡改；
- Canary 5xx/延迟；
- Rollback 失败。

## 4. 生产候选门槛

- Domain ≥90%、Application ≥85%、Adapter ≥70%、总覆盖 ≥75%；
- Critical/High 安全问题清零；
- 重复写动作零重复副作用；
- 跨项目/租户泄漏为零；
- 未签名和 Subject 不匹配发布为零；
- No Data 自动推广为零；
- 真实 Backup/Restore；
- 7×24 无不可恢复 Workflow；
- 从 Deployment 到 Requirement 100% 可追踪。

一个集群不能证明整个集群灾难恢复、跨地域和生产/测试物理故障域隔离，后续必须使用第二集群验证。
