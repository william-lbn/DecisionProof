# 演进路线与竞争壁垒

## 1. 一期

单 GitLab、单组织、单 K8s 集群的产品决策到生产结果闭环。

## 2. 二期

- Jira Product Discovery、Productboard、Aha!、Confluence、SharePoint 连接器；
- GitHub/Azure DevOps；
- 多仓库原子变更；
- 多集群和灾备；
- OpenFGA、SPIFFE；
- Tekton、Harbor、GUAC、Chainloop Adapter；
- Feature Flag 与实验平台。

## 3. 三期

- 生产事故到修复闭环；
- HolmesGPT/SRE Agent；
- 风险自适应自治级别；
- 组织级知识与历史事故规则；
- A2A 跨组织 Agent 协作；
- 产品投资组合和 ROI 归因。

## 4. 核心壁垒

不是模型，而是：

- 来源锚点和决策版本；
- 产品到工程再到生产的统一领域模型；
- 大规模 Evidence Graph；
- Provider Truth 和故障语义数据集；
- Agent 独立审查和权限治理；
- Outcome-bound Release Qualification；
- 企业连接器和实施经验；
- 高风险行业策略模板。
